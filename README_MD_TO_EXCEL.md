# MD to Excel 変換ツール

## 概要
`THIRD_PARTY_LICENSES.md` の内容を自動的にExcelファイル（`hacku_sources_record.xlsx`）に変換するPythonスクリプトです。

## 使用方法

### 1. 必要なライブラリのインストール
```bash
pip install pandas openpyxl
```

### 2. スクリプトの実行
```bash
python convert_md_to_excel.py
```

## 出力ファイル
- **ファイル名**: `hacku_sources_record.xlsx`
- **内容**: MDファイルから抽出された44個のライブラリ・ツール情報
- **列構成**:
  - 番号
  - 使った場所
  - 使った画像/素材/OSSなどのURL
  - 使った画像/素材 (その他/OSS/自作)
  - 使った画像/素材/OSSの規約のURL
  - OKと思った理由

## 統計情報
- **合計ライブラリ数**: 44個
- **OSS**: 30個
- **その他**: 14個

## 特徴
- ✅ 自動的なライセンスタイプ判定
- ✅ 複数行にわたる理由の自動結合
- ✅ Excel形式での美しいフォーマット
- ✅ 文字化け対策済み
- ✅ 列幅の自動調整

## 注意事項
- MDファイルの構造変更時はスクリプトの修正が必要です
- 日本語ファイル名は文字化けを避けるため英語名で出力されます
