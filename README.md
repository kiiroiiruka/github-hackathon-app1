# 🚗 DriveLink

**みんなでつながる、ドライブアプリ**

リアルタイムGPS共有とナビゲーション機能を備えた、グループドライブ用のPWAアプリケーションです。

---

## ✨ 主な機能

### 🗺️ ナビゲーション
- **リアルタイムGPS追跡**：グループメンバーの位置をリアルタイムで共有
- **OSRM APIによるルート案内**：OpenStreetMapベースの高精度ルート計算
- **合流ルート自動生成**：ルートから外れた際の最適な復帰ルート表示
- **休憩地点設定**：マップをタップして休憩地点を設定、別ルートで案内
- **動的ETA表示**：到着予定時刻のリアルタイム更新

### 👥 ソーシャル機能
- **友達管理**：友達の追加・管理
- **グループルーム作成**：複数人でのドライブルーム作成
- **音声通話**：Daily.co APIを使用したリアルタイム音声通話

### 🅿️ 駐車場機能
- **駐車場検索**：現在地周辺の駐車場を検索
- **駐車場情報表示**：料金、空き状況などの詳細情報
- **お気に入り登録**：よく使う駐車場を保存

### 📝 その他
- **運転メモ**：ドライブ中の重要なメモを記録
- **PWA対応**：ホーム画面に追加してネイティブアプリのように使用可能
- **オフライン対応**：Service Workerによるキャッシュ戦略

## 🚀 セットアップ

### 前提条件
- Node.js 18以上
- npm または yarn

### インストール

```bash
# リポジトリをクローン
git clone https://github.com/yourusername/github-hackathon-app1.git
cd github-hackathon-app1

# フロントエンドの依存関係をインストール
cd frontend
npm install

# 開発サーバーを起動
npm run dev
```

### 環境変数

Firebase設定は `frontend/src/firebase/firebaseConfig.js` に記載されています。

## 📱 PWAインストール

### スマートフォン
1. ブラウザでアプリを開く
2. ブラウザメニューから「ホーム画面に追加」を選択
3. アプリアイコンがホーム画面に追加されます

### デスクトップ
1. ブラウザでアプリを開く
2. アドレスバーのインストールアイコンをクリック
3. 「インストール」をクリック

## 🎯 主な最適化

### API呼び出しの最適化
- **ETA更新**: 2分間隔に制限
- **ルート判定**: ローカル計算（1秒間隔）、API呼び出しは必要時のみ
- **ヒステリシス実装**: GPS誤差による不要な再計算を防止
- **重複防止フラグ**: 同時API呼び出しを防止

### パフォーマンス最適化
- **ポリライン最適化**: ズームレベルに応じて表示点数を調整
- **コード分割**: Firebase, React, Leafletを別チャンクに分離
- **Service Worker**: 効率的なキャッシュ戦略
